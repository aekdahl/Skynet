Agent-driven, headless

MCP server image

A slim, headless server image exposing the /mcp endpoint. Deploy it to a sandbox (e.g. Daytona) and let an agent drive Skynet with a bootstrap token.

docker pull ghcr.io/aekdahl/skynet-mcp:latest
TOKEN="skynet_pat_$(openssl rand -hex 32)" docker run --rm -p 8080:8080 \ -e SKYNET_BOOTSTRAP_TOKEN="$TOKEN" \ -e ANTHROPIC_API_KEY="$ANTHROPIC_API_KEY" \ ghcr.io/aekdahl/skynet-mcp:latest
Sandbox & Daytona guide →

MCP endpoint at <url>/mcp, authenticated with your bootstrap token.

Which one do I want?

  • Desktop app — you want to run Skynet yourself and supervise agents from a window on your own machine.
  • MCP server image — you want an agent (or CI, or a Daytona sandbox) to spin Skynet up headless and drive it programmatically over MCP.
